## 1. 핵심 범위

- 일정 인식, 개인 준비 계획, 기본 경로 검색, 환경 기반 웰니스 개입, 도착 확인, 사후 회복 관리

### 이번 개정(v0.4.3) 핵심 결정

- 페르소나 A(일정 많은 대학생) 유지, 페르소나 B → 야외 이동 많은 뷰티·웰니스 관심 사용자로 교체
- 웰니스 = 날씨 정보 표시 ❌ → 환경 노출 부담 계산 + 행동 제안 + 이벤트 푸시 + 사후 회복 리포트 ✅
- 선크림 재도포 알림: 사용자 동의 + 설정 주기 전제. 의료적·피부과적 판단 금지
- 지도 위 날씨·일조량 레이어, 방향 부채꼴, 센서 융합, 보행 속도 추정 → MVP 제외
- 준비시간 입력 화면에 선택형 "나만의 준비 항목" 영역 추가 (영양제, 물·텀블러, 선크림, 마스크 등)
- 담배·주류 등 민감·규제 기호 항목: 앱이 추천 안 함. 사용자 직접 입력 시에만 비공개 개인 루틴으로 처리

## 2. 제품 개요

### 한 줄 정의

Ensom은 사용자의 일정, 실제 준비 패턴, 이동 경로와 환경 정보를 분석해 늦지 않으면서도 서두르지 않도록 준비 시작부터 도착 후 회복까지 관리하는 AI 웰니스 일정관리 비서다.

### 제품이 약속하는 것

- 약속에 늦지 않고 출발 직전에 급하게 움직이지 않는다
- 준비 시간을 직접 역산하지 않아도 된다
- 교통과 날씨 정보를 여러 앱에서 반복 확인하지 않는다
- 우산·마스크·선크림·물 등 필요한 준비 행동을 놓치지 않는다
- 야외 이동이 길거나 환경 부담이 높은 일정에서 선택형 웰니스 리마인드를 받는다
- 준비시간 설정 첫 화면에서 반복 준비물·루틴을 등록하면 이후 다시 입력하지 않는다

### 제품이 제공하는 네 가지 답

1. 언제부터 준비해야 하는가?
2. 언제 출발해야 하는가?
3. 어떤 기본 경로로 이동해야 하는가?
4. 오늘 무엇을 준비하고 언제 다시 챙겨야 하는가?

## 3. 목표 사용자

### 페르소나 A — 일정이 많은 대학생

- 수업·팀 프로젝트·동아리·약속이 반복, 장소가 캠퍼스 안팎으로 자주 바뀜
- 출발 시간을 알고도 준비를 늦게 시작하고 준비물을 빠뜨림
- 필요: 수업 전 준비 시작 시각, 기본 경로, 준비물 체크, 비·자외선·미세먼지 행동 안내

### 페르소나 B — 야외 이동이 많은 뷰티·웰니스 관심 사용자

- 서연, 27세. 외근과 약속이 잦고 피부·환경 관리에 관심
- 자외선·미세먼지·체감온도를 매번 따로 확인하기 어렵고 선크림 재도포 시점을 잊음
- 필요: 일정별 예상 야외 노출 시간, 외출 전 웰니스 체크, 재도포 리마인드, 회복 카드
- 의료 조언보다 짧고 실용적인 뷰티·웰니스 리마인드 선호, 알림 빈도·항목 직접 통제

### 초기 비타깃

- 캘린더를 거의 사용하지 않는 사용자
- 자동차 턴바이턴 내비게이션이 핵심인 사용자
- 전문 의료 진단·치료·복약 관리를 기대하는 사용자
- 상시 위치 추적이나 정밀 운동·건강 측정을 원하는 사용자

## 4. 제품 설계 원칙

1. **빠르게가 아니라 적절하게** — 모든 사용자에게 일찍 출발하라고 요구하지 않음
2. **늦음과 서두름을 함께 줄인다** — 정시 도착률 + 준비 시작 지연 + 극한 알림 + 촉박 평가 모두 봄
3. **정보가 아니라 행동을 제안한다** — 자외선 수치 → 선크림 준비로 변환
4. **웰니스 제안은 맥락이 있을 때만 한다** — 일반 건강 팁 노출 금지
5. **추천 근거를 확인할 수 있어야 한다** — 어떤 환경 정보 때문에 제안됐는지 보여줌
6. **지도는 기본 기능에 집중한다** — 경로·시간·캘린더 저장만. 고급 시각화 MVP 제외
7. **사용자를 질책하거나 건강 상태를 판단하지 않는다** — 실패는 계획 편차로 표현
8. **사용자 통제가 기본값이다** — 웰니스 항목·재알림 간격·잠금화면·위치 자동 확인 등 끌 수 있음

## 5. 화면별 요구사항 요약

### 홈 화면

**필수 정보:**
- 다음 일정명, 시간, 목적지
- 준비 시작 시각, 권장 출발 시각, 도착 예상 시각
- 현재 상태와 선택된 기본 경로
- 사용자 맞춤 준비물·개인 루틴 체크리스트
- 환경 기반 웰니스 행동 최대 3개
- 계산 근거와 계획 조정 사유

**준비시간 초기 화면 구성:**
- 최상단: 준비 시작 시각, 권장 출발 시각, 남은 시간
- 맞춤 준비 영역: 필수 항목 최대 3개 우선 노출 + "더보기"
- 환경 웰니스 영역: 현재 일정·날씨 관련 행동 최대 3개
- "+ 준비 항목 추가": 현재 일정에만 또는 앞으로의 기본 준비 항목으로 저장 선택

**상태별 메시지:**

| 상태 | 메인 메시지 | 보조 메시지 |
|---|---|---|
| 여유 | 아직 여유가 있어요. | 오후 12시 40분부터 준비하면 충분합니다. |
| 준비 시작 | 지금부터 천천히 준비해 보세요. | 오후 1시 20분에 출발하면 제시간에 도착할 수 있어요. |
| 출발 임박 | 이제 출발할 시간이에요. | 현재 경로로 오후 1시 52분 도착 예정입니다. |
| 촉박 | 지금 출발하는 것이 좋아요. | 가장 빠른 기본 경로를 다시 확인했어요. |

### 지도 화면 — MVP 포함/제외

**포함:** 현재 위치·출발지·도착지 검색, 출발/도착 시간 기준 검색, 기본·대체 경로 비교, 예상 이동 시간·도보·환승, 캘린더 저장

**제외:** 날씨·자외선·미세먼지 지도 레이어, 방향 부채꼴·센서 융합, 개인 보행 속도 추정, AR·실내 측위·턴바이턴 음성 안내, 자체 지도 타일·경로 엔진

### 지도 → 캘린더 저장 흐름

1. 출발지·도착지 검색 + 출발/도착 시각 지정
2. 기본 경로 중 하나 선택
3. "캘린더에 추가" 선택
4. 출발지·도착지·시각·선택 경로가 자동 입력된 일정 생성 화면 이동
5. 일정명 입력 + 저장할 캘린더 선택
6. 최종 일정 시간 기준으로 준비 계획과 웰니스 행동 재계산

### 최초 가입 흐름

1. 소셜 로그인
2. 필수 약관 동의
3. 캘린더 권한 요청
4. 위치 권한 요청
5. 첫 준비 계획 생성 후 알림 권한 요청
6. 대략적인 준비 시간 입력 또는 "잘 모르겠다" 선택
7. 주요 장소 설정
8. 선택적 웰니스 관심 항목 설정

### 준비시간 화면 맞춤 준비 항목

| 구분 | 빠른 추가 예시 | 기본 처리 |
|---|---|---|
| 반복 준비물 | 영양제, 물·텀블러, 선크림, 마스크, 우산, 보조배터리 | 체크리스트. 사용자가 시간 지정 시에만 준비 시간 반영 |
| 개인 기호 품목 | 커피·차·간식 등 사용자가 직접 선택한 품목 | 챙기기/구매하기로 등록 |
| 시간 소요 루틴 | 렌즈, 화장, 식사, 반려동물 돌보기, 직접 입력 | 설정한 분만큼 준비 시간에 합산 |
| 민감 항목 | 복용약, 사용자가 직접 입력한 비공개 루틴 | 잠금화면에는 일반화된 이름으로 표시 |

> **앱은 영양제·복용약·기호 품목을 추천하거나 섭취 필요성·용량·효능을 판단하지 않는다.** 사용자가 직접 등록한 준비 행동을 일정 맥락에 맞춰 기억하고 확인하는 역할만 수행한다.

## 7. 핵심 사용자 여정

### 시간 계산식

```
목표 도착 시각 = 일정 시작 시각 - 도착 여유 시간
권장 출발 시각 = 목표 도착 시각 - 예상 이동 시간 - 교통 버퍼
준비 시작 시각 = 권장 출발 시각 - 개인 준비 시간 - 상황별 추가 준비 시간 - 개인 루틴 시간
```

### 일정 중 웰니스 이벤트 알림 조건 (전부 AND)

1. 사용자가 해당 웰니스 항목과 이벤트 알림을 켰다
2. 환경 노출 우선순위가 설정 임계값 이상이다
3. 예상 또는 확인된 야외 노출이 계속된다
4. 사용자가 설정한 재알림 간격에 도달했다
5. 같은 행동에 대해 이미 완료·해제하지 않았다

## 8. 알림 체계

### 시간 관리 알림 3종

| 유형 | 설명 |
|---|---|
| **여유 알림** | 충분한 시간 전에 준비 계획 미리 인식 |
| **극한 알림** | 정시 도착을 위해 즉시 행동해야 하는 시점 |
| **돌발 알림** | 교통·기상 변화로 계획 수정 필요 시. 사소한 변화는 푸시 없이 로그에만 |

### 웰니스 이벤트 알림 (별도 동의)

- 사용자가 선택한 항목에만 발송
- 일정과 야외 노출 맥락이 있어야 함
- 완료·미루기·오늘은 그만 액션 제공
- 같은 일정의 동일 항목은 기본 **1회 제한**

### 알림 수 제한

- 일정당 시간 관리 핵심 알림: 기본 최대 **3회**
- 웰니스 이벤트 알림: 별도 동의 시 일정당 기본 최대 **1회**

## 9. 웰니스 모델

### WIS (일정 웰니스 행동 우선순위 점수)

```
WIS = min(100, 100 × (0.35U + 0.25P + 0.20T + 0.20O) × M)
```

| 변수 | 의미 |
|---|---|
| U | 자외선 부담 정규화값 0~1 |
| P | 미세먼지·대기질 부담 정규화값 0~1 |
| T | 체감온도·강수 기반 열환경 부담 정규화값 0~1 |
| O | 예상 야외 이동 시간 정규화값 0~1 (상한 120분) |
| M | 사용자 관심 항목 보정계수 1.0~1.25 |

**WIS 구간:**
- 0~39: 일정 상세 카드에만 표시. 푸시 없음
- 40~69: 외출 전 준비 카드에 행동 1~2개
- 70~100: 외출 전 행동 제안 + 웰니스 이벤트 알림 후보 생성

> **WIS는 의료 위험도나 피부 상태 점수가 아니다.** 어떤 웰니스 행동을 언제 노출할지 결정하는 내부 우선순위 점수다.

### RLS (촉박함 부담 점수)

```
RLS = min(100, 100 × (0.45Dp + 0.35Dd + 0.20E))
```

- RLS는 사용자의 스트레스나 정신건강을 측정하지 않음. **운영 지표 전용**

### DWL (일일 웰니스 부담 지수)

```
DWL = 0.6 × 일정별 WIS의 야외 시간 가중평균 + 0.4 × 일정별 RLS 평균
```

- `dwlBand`만 UI에 노출. `dwlScore`는 내부 분석 전용

### 선크림 재도포 기능 원칙

- 사용자가 기능을 켜고 재알림 주기를 **직접 설정**해야 함
- **SPF·피부 타입·제품 성능에 따른 재도포 주기를 서비스가 판단하지 않음**
- 예상 야외 노출이 계속될 때만 알림 후보 생성

### 의료·뷰티 경계

- 진단, 치료, 복용량, 피부 상태 판정, 제품 효능 보장 금지
- 영양제·복용약·개인 기호 품목은 **사용자가 입력한 준비 항목으로만** 취급

## 10. 준비 시간 모델

### 설계 원칙

> 자기 보고는 시드이고 관측된 편차가 진실이다.

| 신호 | 정의 |
|---|---|
| `t_plan_prep` | 서비스가 권장한 준비 시작 시각 |
| `t_actual_prep` | 사용자가 준비 시작을 누른 시각 |
| `t_plan_depart` | 권장 출발 시각 |
| `t_actual_depart` | 사용자 입력 또는 위치 기반 출발 시각 |
| `t_arrive` | 실제 또는 확인된 도착 시각 |

```
P_new = (1 - alpha) × P_old + alpha × D_actual
alpha 초기값 = 0.3
한 번의 준비 시간 보정 상한 = 15분
기록 3회 미만: 보수적으로 시드값 사용
```

## 12. 성공 지표

### 북극성 지표

> Ensom의 준비 계획을 통해 늦지 않고 여유 있게 도착한 **주간 일정 수**

### 가드레일 지표

- 알림 전체 차단율 + 웰니스 알림 개별 해제율
- 불필요하거나 맥락이 맞지 않다는 웰니스 알림 비율
- "오늘은 그만" 선택률과 반복 무시율
- 의료 조언으로 오해했다는 문의 비율
- 자동 보정 되돌림률과 개인화 초기화율

## 13. 데이터 및 개인정보

### 최소 수집 원칙

- 일정 전체 메모와 참석자보다 시간과 장소를 우선
- 하루 전체 이동 경로를 기본 저장하지 않음
- 출발·도착 확인은 해당 일정과 관련된 지오펜스 이벤트만 사용
- 건강 관련 자유 입력과 주요 장소는 암호화하고 최소 권한으로 접근

### 민감 정보

- 집·직장 위치, 개인 루틴, 복용약·영양제·기호 품목, 위치 기반 출발·도착 기록
- 잠금화면에서 상세 항목 숨김 가능

## 14. 비기능 요구사항

- 다음 일정 카드와 준비 계획: **5초 이내** 표시
- WIS와 행동 제안: **2초 이내** 생성
- 지도·날씨·교통 API 일부 실패 시 앱 전체 중단 없음
- 환경 데이터 없으면 웰니스 제안 생략, 시간 계획은 정상 제공
- 연속 GPS 추적 기본값으로 사용하지 않음 (지오펜싱 우선)

## 15. 디자인 시스템 방향

- **키워드**: 서양식 미니멀, 쿨톤, 넓은 여백, 선명한 타이포그래피, 정보 우선순위 명확한 카드
- **웰니스 카드**: 한 화면 최대 3개, 환경 수치보다 이유와 행동을 먼저, 완료·미루기·숨기기 한 탭
- **네비게이션**: 홈·지도·캘린더·설정 하단 탭 바
- **카피 톤앤매너**: 재촉하거나 평가하지 않음. 계획 조정에 초점
