화면 연결 맵

노드를 골라주세요

왼쪽 다이어그램에서 화면 하나를 누르면 그 화면의 진입 경로, 화면 안의 동작이 어디로 이어지는지, 뒤로가기가 어디로 가는지, 지켜야 할 조건을 보여드려요.

상단 필터로 영역만 골라 볼 수 있어요.

전이 타입

  • 탭 탭 전환. 스택을 쌓지 않음
  • 푸시 스택에 쌓임. 뒤로가기로 복귀
  • 시트 모달. 닫으면 뒤 화면 유지
  • 교체 스택 비우고 갈아탐. 복귀 불가
