v1과 뭐가 달라졌나

1. 다크 패널을 하나의 컴포넌트로

날짜 영역 전체를 라운드 30px 다크 패널에 담았습니다. 이전 결과물이 문제였던 건 "검정을 썼다"가 아니라 화면 여기저기에 정체불명의 검정 블록이 흩어져 있었기 때문이에요. 하나의 정의된 패널로 쓰면 상단 바가 다크인 것과 같은 논리라 시스템 안에 들어옵니다.

대신 상단의 다크 앱바를 없앴습니다. 다크 바 + 다크 패널이 세로로 붙으면 화면 위쪽이 통째로 검게 막혀 보여서요. 워드마크는 텍스트로만 남겼습니다.

2. 날짜 상태를 4단계로

  • 기본 — 테두리 없음, 흰 글씨 72%
  • 일정 있는 날 — 라임 링(테두리)만. 채우지 않아서 과하지 않음
  • 오늘 — 라임 채움
  • 선택 — 흰색 채움

일정이 2개 이상인 날은 우하단에 작은 개수 배지가 붙습니다. 점 대신 숫자라 "얼마나 바쁜 날인지"가 바로 읽혀요.

3. 리스트를 타임라인으로

레퍼런스처럼 왼쪽에 시각 레일을 두고 세로선으로 연결했습니다. 카드만 나열하는 것보다 "하루가 흘러간다"는 감각이 생겨요. 다음 일정 카드만 테두리가 진해집니다.

4. 카드 하단에 경로 요약

이동이 있는 일정만 구분선 아래에 "환승 1회 · 42분 · 12:40 준비 시작"이 붙고 [경로] 버튼이 생깁니다. 온라인 일정은 이 영역 자체가 없어서 카드 높이가 달라지고, 그것만으로 두 종류가 구분됩니다.

5. 필터 칩 추가

전체 / 이동 있음 / 온라인. 앤섬은 "이동이 필요한 일정"이 핵심이라 이 축의 필터가 실제로 쓸모 있습니다.
