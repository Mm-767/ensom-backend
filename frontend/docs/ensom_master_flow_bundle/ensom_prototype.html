이 프로토타입에서 확인할 것

1. 라임 면적

히어로 카드가 화면의 약 30%를 차지합니다. 이전 결과물(40~50%)보다 줄였어요. 상태를 바꿔봐도 카드 높이가 크게 변하지 않는지 보세요.

2. 뒤 카드가 오른쪽으로 삐져나옴

레퍼런스대로 뒤 카드를 오른쪽으로 밀었습니다. 위아래로도 살짝 좁혀서 계단처럼 보이게 했어요.

라임 카드 가로 폭을 줄여서 뒤 카드가 화면 밖으로 나가지 않게 했습니다. 삐져나오는 폭은 한 장당 19px이고, 뒤 카드 개수에 따라 라임 카드 폭이 자동으로 줄어듭니다 — 1장이면 19px, 2장이면 38px. 그래서 일정이 1개일 때는 라임 카드가 화면 폭을 꽉 채우고, 3개일 때만 좁아져요. 개수를 바꿔가며 라임 카드가 너무 좁아 보이지 않는지 확인해 보세요.

surface-2 → surface-neutral 순으로 뒤로 갈수록 어둡습니다. 레퍼런스는 뒤 카드가 진회색이었지만 "다크 컨테이너 금지" 규칙과 충돌해서 연회색으로 잡았어요.

3. 상태 구분이 색 없이 되는가

5개 상태 모두 라임을 유지하고, 타이포 크기·정보량으로만 긴박도를 표현합니다. 출발 임박은 숫자가 가장 크고 보조 정보가 줄어들며, 촉박만 배지가 앰버로 바뀝니다. 상태를 번갈아 눌러보면서 구분이 되는지 판단해 보세요.

4. 한글 줄바꿈

word-break:keep-all을 적용해서 조사가 다음 줄로 넘어가지 않습니다. 이전 결과물의 "20분 뒤 준비 / 를 시작하세요" 문제가 재현되는지 확인용이에요.

5. 일정 개수별 레이아웃

0개일 때 히어로가 흰 카드로 바뀌고, 5개일 때 뒤 카드는 2장까지만 쌓이고 "모두 보기"로 넘어갑니다. 개수를 바꿔도 카드 시작 위치가 흔들리지 않는지 보세요.

남은 판단

  • 뒤 카드에 시각만 노출할지, 일정명까지 노출할지
  • 뒤 카드 회색을 한 단계 더 진하게 갈지
  • 웰니스 태그 2개가 라임 카드와 같이 있을 때 라임이 과한지
