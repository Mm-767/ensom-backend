연결된 흐름

홈과 캘린더 양쪽에서 같은 상세 화면으로 들어갑니다. 상세에서 뒤로가기를 누르면 들어온 곳으로 돌아가요.

홈 → 라임 히어로 카드 탭 → 강남역 미팅 상세
홈 → 뒤쪽 회색 카드 탭 → 그 일정의 상세
캘린더 → 일정 카드 탭 → 상세
상세 → 좌상단 ‹ → 왔던 화면으로

일정별로 화면이 달라집니다

  • 강남역 미팅 — 이동 있음. 경로 구간, 웰니스 제안 전부 표시
  • 디자인 리뷰 — 온라인 일정. 경로 섹션과 웰니스 섹션이 아예 없어지고 시간 계획도 준비 시간만 남습니다
  • 저녁 약속 — 이동 촉박. 상태 배지가 앰버로

온라인 일정을 눌러보면 "이동이 없으면 화면이 이만큼 비어야 한다"는 게 보입니다. 섹션을 비워두는 게 아니라 통째로 없애는 방식이에요.

캘린더 날짜도 눌러집니다

패널의 날짜를 누르면 아래 리스트가 그 날로 바뀝니다. 우상단 두 버튼으로 주간/월간 전환도 돼요. 일정이 없는 날(8/22)도 눌러보세요.

확인 포인트

  • 세 화면을 오갈 때 같은 앱으로 느껴지는가
  • 다크 패널이 캘린더·상세 두 곳에 나오는데 과한가
  • 홈의 라임 카드 → 상세의 다크 패널 전환이 어색하지 않은가
  • 온라인 일정 상세가 너무 비어 보이지 않는가
