이번에 더한 것

1. 하단 탭바를 항상 유지

시트가 탭바를 덮지 않고 그 위로 올라옵니다. 시트 안쪽 아래 여백(88px)을 확보해서 CTA가 탭바에 가리지 않아요. 지도는 탭 루트 화면이라 어떤 상태에서도 다른 탭으로 나갈 수 있어야 합니다.

2. 출발·도착 입력 ★

기존엔 검색창 하나뿐이었는데, 경로 검색은 두 지점이 필요합니다. 상단 박스에 출발(회색 점)·도착(라임 마커) 두 줄과 뒤집기 버튼을 넣었어요. 출발지 기본값은 "현재 위치"이고 주요 장소(집·직장)로 바꿀 수 있습니다.

3. 시각 기준 토글 ★

화면설계서 S-08에 있는데 지금까지 어떤 화면에도 없던 겁니다. 도착 시각 기준과 출발 시각 기준을 바꾸면 경로 카드의 표시가 "14:00 도착"에서 "지금 출발 → 14:06 도착"으로 바뀝니다.

앤섬에선 이게 특히 중요해요. "2시 약속"은 도착 시각 기준이고, 여기서 역산해야 준비 시작 시각이 나옵니다. 기본값을 도착 시각 기준으로 둔 이유예요.

4. 검색 전체화면 ★

상단 검색 아이콘이나 검색창을 누르면 전체화면 검색으로 갑니다. 입력하기 전엔 최근 검색·주요 장소가 뜨고, 실제로 타이핑하면 결과가 필터링됩니다. "강남", "서울", "홍대" 등을 쳐보세요. 없는 걸 치면 결과 없음 상태도 볼 수 있어요.

5. 경로 실패 상태

화면을 덮는 오류 화면 대신 시트 상단 배너로 처리했습니다. 마지막 성공 경로는 그대로 보여주고 "14:31 기준"만 명시해요. 빨강 없이 중립 회색 배너입니다.

6. 지도 저작권 표기

지난번 지적한 대로 좌하단에 "© Kakao"를 넣었습니다. 우하단은 현위치 버튼 자리라 겹쳐서요. 실제 연동 시 카카오 가이드라인 확인이 필요합니다.

7. 구간 비율 바 ★ (네이버 참고)

각 경로 카드에 소요 시간에 비례하는 가로 바를 넣었습니다. 펼치지 않아도 "이 경로는 버스가 대부분이구나", "이건 도보가 길구나"가 한눈에 들어와요. 세 경로를 나란히 놓고 바 모양만 비교해도 성격 차이가 읽힙니다.

네이버와 다르게 한 점: 조각을 붙이지 않고 2px 띄우고 각각 라운드를 줬습니다. 앤섬은 직각 모서리를 쓰지 않는 시스템이고, 띄우면 환승 지점이 더 명확해집니다.

색은 이미 정한 transit-* 토큰 그대로예요 — 2호선 초록, 3호선 주황, 간선버스 파랑, 도보는 중립 회색. 새 색을 만들지 않았습니다.

조각이 좁으면 글자를 자동으로 뺍니다. 13% 이상이면 "12분", 7% 이상이면 숫자만, 그보다 좁으면 색만 남아요. 도보 1분짜리도 바에서 사라지지 않게 최소 폭을 뒀습니다.

8. 접힘 상태가 쓸모 있어짐

시트를 접으면 선택한 경로의 요약 + 구간 바만 남습니다. 지도를 넓게 보면서도 경로 구성은 계속 보이는 상태예요. 손잡이를 눌러보세요.

남은 판단

  • 바에 요금(3,300원)도 넣을지 — 네이버는 넣는데 앤섬 PRD엔 요금 개념이 없음
  • 출발·도착 박스가 상단바 바로 아래라 지도 가시 영역이 줄어듦 — 시트 안으로 넣을지
  • 시각 기준 토글을 시트가 아니라 상단 박스에 붙일지
  • "공유" 버튼이 실제로 필요한지 (PRD엔 없는 기능)
