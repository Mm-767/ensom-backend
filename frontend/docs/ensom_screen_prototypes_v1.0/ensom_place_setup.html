등록된 장소 — 집·직장이 이미 등록돼 있어. 행을 탭하면 유형은 그대로 두고 주소 검색부터 다시 밟아 수정할 수 있어.

새 장소 추가 — "+ 장소 추가" → 유형 선택(기타는 이름 직접 입력) → 주소 검색("강남"이라고 타이핑해보면 결과가 실시간으로 6개 정도 좁혀져) → 지도에서 핀 조정 순서로 진행돼.

핀 조정 — 핀은 화면 중앙에 고정, "지도 움직이기" 칩을 누르면 주소 텍스트가 실제로 바뀌어(지도 패닝을 흉내). 저장하면 목록에 실제로 반영되고 토스트가 떠.
