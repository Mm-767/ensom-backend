이 화면의 설계 판단

1. 시간 계획을 다크 패널로

캘린더의 날짜 패널과 같은 컴포넌트를 재사용했습니다. 두 화면이 "같은 앱"으로 묶이는 가장 큰 장치예요. 준비 시작 → 출발 → 도착 세 지점을 트랙 위 노드로 찍고, 현재 위치까지만 라임으로 채웠습니다.

홈의 라임 히어로 카드가 "지금 상태"를 말한다면, 여기 다크 패널은 "하루의 계획 전체"를 보여줍니다. 역할이 달라서 색도 다릅니다.

2. 계산 근거는 접어둠

기본은 "총 80분" 한 줄만. [자세히]를 누르면 개인 준비·준비 항목·이동·도착 여유로 쪼개집니다. PRD의 "근거를 항상 제공하되 전면에 내세우지 않는다" 원칙에 맞췄어요. 직접 눌러보세요.

3. 준비 항목 vs 웰니스 행동

같은 체크리스트지만 시각적으로 다릅니다 — 준비 항목은 텍스트만, 웰니스 행동은 라임 이유 태그가 붙어요. "내가 등록한 것"과 "환경 때문에 제안된 것"의 구분입니다. 체크하면 태그도 같이 회색으로 죽습니다.

4. 경로 구간 색상 적용

지난번 정한 대중교통 색상을 처음으로 실제 적용했습니다. 7호선 #747f00, 간선버스 #3a7dd0, 도보는 배지 없이 회색 아이콘만. 경로 요약을 눌러 펼쳐보세요.

배지가 작아서(9.5px, 3×8 패딩) 라임이나 CTA와 경쟁하지 않는지가 확인 포인트입니다.

5. WIS 점수는 표시하지 않음

PRD §8.7에 따라 어디에도 점수·등급 숫자가 없습니다. 웰니스는 "왜 제안됐는지"(자외선 높음 · 야외 12분)로만 표현돼요.

6. 종료 후 결과

상단 토글을 "종료 후"로 바꾸면 결과 섹션이 나타나고, 하단 CTA가 사라지며 사후 평가 칩이 생깁니다. 판정이 확실할 때는 질문을 안 띄운다는 규칙이 있어서, 실제로는 애매한 경우에만 이 질문이 나옵니다.
