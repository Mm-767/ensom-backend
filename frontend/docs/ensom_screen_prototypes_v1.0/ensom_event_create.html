제목 · 저장 버튼 — 제목을 입력하기 전에는 상단·하단 저장 버튼이 진짜 disabled 상태(포인터 이벤트 자체가 막힘)야. 타이핑하면 실시간으로 활성화돼.

장소 필요 여부 — 3단 세그먼트. "장소 필요"를 고르면 목적지 검색 필드가 나타나고, 예시 결과를 탭하면 채워진 행(변경 가능)으로 바뀌어. "장소 불필요"는 이동 계획이 없다는 안내만 남겨. "미지정"인 채로 저장을 누르면 분류 확인 시트가 열려.

분류 확인 시트(S-11) — "잘 모르겠어요"를 고르면 강제로 답을 정하지 않고 필드 옆에 "나중에 다시 확인할게요" 캡션만 남긴 채 저장이 진행돼(1회 응답 후 재질문 없음). 시트 바깥을 눌러도 닫히지 않아 — 세 선택지로만 닫혀.

시작 시각 — 값 표시 행을 탭하면 날짜 칩 + 시각 빠른 조정(+30분/+1시간/특정 시각) 패널이 펼쳐지고, 표시값이 실제로 바뀌어.

만들기·수정 모드 — 폰 상단 칩으로 전환. 수정 모드는 기존 일정(강남역 미팅) 샘플 데이터를 불러와.

지도 프리필 데모 — 같은 줄 오른쪽 버튼이 지도 화면이 postMessage로 보낼 법한 프리필(목적지·날짜·시각)을 그대로 재현해 — 실제 발신 화면 없이도 프리필 상태를 볼 수 있어.
