# Ensom 화면 프로토타입 — 개별 파일 패키지

HTML 파일 27개. 각 파일은 **외부 의존성이 전혀 없는 단일 HTML**이라 그냥 브라우저로 열면 바로 동작한다. 파일 하나 안에 여러 화면이 들어 있고, 폰 목업 상단의 **작은 칩 줄**을 누르면 화면이 전환된다.

디자인 토큰·컴포넌트 CSS는 27개 파일 전부 동일하게 맞춰져 있으니, 아무 파일에서나 `:root` 블록과 컴포넌트 클래스를 그대로 가져다 쓰면 된다.

## 구현할 때 알아둘 것

**디자인 토큰** — 모든 파일 `:root`에 동일하게 들어 있다.

```css
--lime:#c6f135;  --lime-soft:#e4fb9b;  --lime-ink:#4e6810;
--canvas:#ffffff; --surface-1:#ffffff; --surface-2:#eef0ea; --surface-neutral:#e9e9e6;
--hairline:#e3e5e0; --ink:#14150f; --ink-muted:#63655e; --ink-faint:#6f7269;
--panel:#15170f; --cta:#1f231a; --caution:#e3a13b;
```

**색 사용 규칙**
- 라임은 아주 작은 포인트에만. 큰 라임 면은 홈 히어로 카드와 온보딩 첫 계획 카드 정도.
- 기본 CTA 버튼 = `--cta`(#1f231a) 배경 + 흰 글자.
- **빨강은 어디에도 쓰지 않는다.** 오류·삭제·경고도 `--caution`(앰버) 또는 중립색.
- 팔레트 밖 색(파랑 등) 금지. Google 로고 4색만 예외.

**상단 바는 흰색/투명.** (초기 디자인 문서에는 다크로 적혀 있으나 흰색으로 확정됨)

**토글 스위치** — 꺼짐 = 연회색 트랙 + 흰 손잡이(왼쪽), 켜짐 = 차콜 트랙 + **라임** 손잡이(오른쪽).

**폰 목업 상단의 칩 줄(`.selrow`)과 페이지 바깥 설명(`.page-head`, `.legend`)은 전부 QA용이다.** 실제 구현에는 넣지 않는다.

**카피 톤** — 재촉하지 않고, 사용자를 평가하지 않는다. "~해 주세요", "~하는 게 좋아요" 같은 제안형. 느낌표 남발·이모지 금지.

## 프로토타입에서 확정된 규칙

- 다이얼로그는 전부 중앙 팝업. 회원탈퇴처럼 페이지 자체가 있는 경우만 예외.
- 조건부 필드(루틴 선택 시 소요시간, 장소 필요 선택 시 목적지)는 애니메이션 없이 즉시 나타나고 사라진다.
- 사후 평가 폼은 판정이 애매할 때만 등장. 정시 도착이면 섹션 자체가 없다.
- "앱이 판단하지 않는다"는 안내 문구(선크림 재도포 주기 등)는 해당 기능을 꺼도 사라지지 않게 고정 노출.
- 분류 확인에서 "잘 모르겠어요"는 상태를 강제 확정하지 않고 미해결로 남긴다. 재질문도 없다.
- 민감 항목(복용약)은 잠금화면 숨김이 강제 ON이고 사용자가 끌 수 없다.
- 권한을 거부해도 앱이 막히지 않는다. 전면 오류 대신 인라인 배너로 알리고 대체 수단을 함께 안내한다.
- 필수 약관 미동의만이 유일하게 진행을 막는 게이트다.
