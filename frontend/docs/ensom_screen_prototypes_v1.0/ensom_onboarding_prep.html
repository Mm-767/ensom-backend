Ensom — 준비 시간 + 나만의 준비 항목 (온보딩)

온보딩 중 준비 시간 시드값과 반복 준비 항목을 한 화면에서 입력받는 화면(S-03). 준비 시간 칩은 단일 선택, 빠른 추가 칩은 다중 선택이며 항목을 켜면 구분·소요 시간·잠금화면 표시 여부를 정하는 시트가 뜬다. "복용약"은 시트가 열리는 순간 잠금화면 숨기기가 강제로 고정된다.

복용약은 정책상 항상 잠금화면에서 이름을 숨겨요

준비 시간 칩 — 단일 선택(라디오)이라 하나를 고르면 이전 선택은 자동으로 풀려. "잘 모르겠어요"를 고르면 기본값 30분으로 시작한다는 안내 문구가 아래 나타나.

빠른 추가 칩 — 다중 선택(토글)이야. 켜면 바로 상세 시트가 뜨고, 구분에서 "시간이 필요한 루틴"을 고를 때만 소요 시간 입력 필드가 나타나. 칩을 다시 탭하면 꺼지면서 저장된 시트 데이터도 함께 지워져.

복용약 특수 규칙 — 시트가 열리는 순간 "잠금화면에서 항목명 숨기기"가 강제로 켜지고 잠겨서(반투명 + 클릭 무시) 끌 수 없어. 정책상 항상 민감 항목으로 취급돼.

직접 추가 — 탭하면 토글되지 않고 인라인 입력창이 열려. 이름을 입력해 추가하면 새 칩이 그 자리에 생기고 바로 그 칩의 시트가 열려 구성할 수 있어.

하단 저장 — 아무 것도 선택하지 않아도 "저장"과 "나중에 설정할게요" 둘 다 항상 눌려. 이 단계는 건너뛰어도 온보딩이 막히지 않아.
