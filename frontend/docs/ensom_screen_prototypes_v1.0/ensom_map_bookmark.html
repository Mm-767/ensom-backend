선택한 북마크를 삭제할까요?

삭제한 북마크는 되돌릴 수 없어요.

기본 지도 — 검색 전 지도 탭의 첫 화면. 현재 위치, 주요 장소(집·직장), 북마크 핀만 조용히 보여주고 나머지 지도 컨트롤은 넣지 않았습니다.

북마크 저장 — 장소를 고르면 뜨는 상세 시트. 별을 켠 직후에만 폴더 선택이 인라인으로 나타나고, 끄면 사라집니다.

목록 · 편집 · 빠른 선택은 같은 북마크 배열을 공유합니다. 편집에서 지우면 목록과 빠른 선택에서도 함께 사라져요.
