배너는 사용자가 닫으면 그 세션 동안 다시 뜨지 않아요. 전면 오류 화면으로 막지 않습니다.

권한 현황 — 상태 배지를 누르면 허용됨 → 허용 안 함 → 미결정 → 허용됨 순으로 순환하고, 카드 안의 대체 안내와 버튼이 상태에 맞게 바뀝니다.

거부 화면 3종 — 프라이밍 화면과 같은 레이아웃. 아이콘은 사선으로 꺼진 상태를 표현하고, 항상 "…없이도 할 수 있어요" 대체 수단을 함께 보여줍니다. 캘린더는 대체 경로(일정 직접 만들기)를 1순위 버튼으로 둡니다.

기능 제한 배너 — 전면 차단 대신 인라인 배너. ×로 닫으면 사라지고, 모두 닫으면 다시 보기 버튼이 나타납니다.
